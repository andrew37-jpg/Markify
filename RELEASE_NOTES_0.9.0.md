# Markify v0.9.0 — Цеха и массовая печать

## Главное

- Добавлены рабочие цеха: **Горячий цех**, **Пицца**, **Сушибар**, **Холодный цех**.
- Администратор/менеджер может добавлять, переименовывать и убирать дополнительные цеха.
- Продукты можно назначать в цех по одному или массово.
- Один продукт принадлежит одному активному цеху одновременно.
- В старых маркировках без сохранённого цеха при распределении продукта выполняется безопасный backfill, чтобы просроченная маркировка отображалась в правильном цехе.
- На главном экране цеха стали отдельными быстрыми вкладками.
- Продукты и маркировки фильтруются по выбранному цеху.
- Карточка **«Просрочены»** вынесена наверх.
- В таблице контроля добавлена отдельная колонка **«Цех»**.
- История печати также показывает цех.
- Добавлена кнопка **«Распечатать всё»** для выбранного цеха.
- Массовая печать создаёт отдельное задание для каждого продукта с подтверждённым автоматическим сроком.
- Продукты с ручным/неподтверждённым сроком намеренно не печатаются автоматически: они возвращаются в список пропущенных с причиной.
- Сохраняется прямая печать через Print Agent; браузерный PDF-сценарий не используется.
