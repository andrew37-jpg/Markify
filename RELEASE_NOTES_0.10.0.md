# Markify 0.10.0 — универсальный слой печати

## Что сделано

- Добавлен отдельный слой Printer Adapter в `app/printer_adapters.py`.
- Print Agent больше не содержит разрастающуюся цепочку `if driver == ...`: протокол выбирается через единый адаптер.
- Поддержаны драйверы/режимы:
  - Xprinter / TSPL
  - Zebra / ZPL
  - TSC / TSPL
  - Godex / RAW
  - ESC/POS
  - Generic RAW TCP 9100
  - Atol через системный драйвер/CUPS
  - CUPS / системный драйвер
- Существующий `xprinter` сохранён для обратной совместимости.
- Для системных принтеров используется локальный CUPS на компьютере с Print Agent; облачный сервер не получает прямой доступ к USB.
- Сообщения интерфейса больше не привязаны к Xprinter как к единственному варианту.
- Существующая защита от повторной физической печати при сбое callback сохранена.

## Проверка

- `python -m compileall -q app agent tests` — OK
- `python -m pytest -q` — **42 passed**

## Ограничение

Производитель сам по себе не гарантирует единый протокол у всех моделей. Для Atol/Godex и других моделей, которым нужен фирменный драйвер, выбирается системный драйвер/CUPS либо конкретный протокол. Физическая печать каждой модели требует отдельной проверки на реальном устройстве.
