Подключение

На Windows выберите Windows / USB и укажите точное имя установленного принтера. Размер и ориентация бумаги в драйвере должны совпадать с Markify. На macOS/Linux USB-принтеры подключаются через системный драйвер CUPS на компьютере с Print Agent. Для LAN-принтеров укажите IP и порт 9100. Токен Print Agent показывается один раз только при создании подключения. Сохраните его в защищенном месте.
