# Markify 0.4 — аудит текущей версии

## Что было найдено по записи экрана

1. Карточки продуктов визуально присутствовали, но сценарий клика был ненадежным: JavaScript зависел от отдельного статического файла, который в установленной пользователем версии отсутствовал/не совпадал с шаблонами.
2. Страницы смешивали быстрый печатный сценарий и администрирование. Для кухни это создавало лишние поля и клики.
3. Модальное окно печати отсутствовало в надежном сценарии текущей установленной версии.
4. Таблица контроля не разделяла рабочий сценарий кухни и справочник продуктов.
5. Старые SQLite-базы имели несовместимую схему, а миграция v0.3 обновляла только часть полей. В результате приложение падало на `products.shelf_life_minutes`.
6. Печать открывалась через асинхронный `window.open`, что могло приводить к блокировке popup браузером.
7. В модели не было отдельной сущности печатного задания, поэтому пачечная печать и история перепечаток были слабо связаны.

## Что исправлено в 0.4

- Полный рабочий каталог из 147 позиций, импортированный из предоставленного PDF.
- Реальные кликабельные карточки `button` с изображением и названием.
- Поиск и фильтрация по категориям.
- Модальное окно печати.
- Счетчик количества 1–100.
- Безопасный popup печати: пустое окно открывается синхронно по клику, затем получает URL задания.
- Два режима срока: автоматический только для подтвержденного значения и ручной ввод `Годен до` по документу.
- Сервер всегда рассчитывает автоматический срок.
- История печатных заданий и отдельные этикетки.
- Фиксация открытия диалога печати в audit log.
- Идемпотентная additive-миграция для старых SQLite.
- Каталог позволяет подтверждать срок, задавать пороги и основание.
- 147 технических SVG-иллюстраций для карточек; их можно заменить реальными фотографиями.
- Тесты API/сервисного слоя.

## Почему в базе нет выдуманных сроков

Предоставленный PDF содержит перечень продуктов, но не содержит для каждой позиции точного срока годности и режима хранения после вскрытия. Поэтому 147 позиций импортированы, но для них не проставлены вымышленные минуты хранения.

Для пищевой продукции срок годности и условия хранения устанавливает изготовитель; для продукции собственного производства общепита сроки должны соответствовать утвержденной технической документации. Markify 0.4 специально блокирует автоматический расчет до тех пор, пока конкретное значение не подтверждено.
