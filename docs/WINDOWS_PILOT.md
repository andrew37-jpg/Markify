# Тест Markify на Windows, Xprinter XP-365B / USB002

1. Установите драйвер принтера. В Windows напечатайте его тестовую страницу. USB002 — порт; скопируйте точное имя принтера из Windows.
2. Установите Python 3.12. Распакуйте архив агента в отдельную папку. В PowerShell из этой папки:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-agent.txt
Copy-Item agent\.env.example agent\.env
```

3. Откройте временную ссылку, войдите, откройте «Принтеры». Добавьте Windows / USB. Укажите точное имя принтера Windows в поле очереди, фактические ширину/высоту этикетки и DPI. Host оставьте пустым. Настройте тот же размер бумаги и ориентацию в предпочтениях печати драйвера Windows. Не выбирайте PDF-принтер. Токен показан один раз — сохраните его.
4. В agent/.env укажите MARKIFY_URL (временная HTTPS-ссылка) и MARKIFY_AGENT_TOKEN (выданный токен).
5. Проверьте подключение и запустите агент:

```powershell
.\.venv\Scripts\python.exe agent\agent.py --check
.\.venv\Scripts\python.exe agent\agent.py
```

6. Оставьте окно агента открытым. Создайте тестовую маркировку с ручным будущим сроком. Сначала одна этикетка, потом две. Сверьте кириллицу, даты, размер, отступы и подачу. Проверьте «Повторить» — даты должны остаться прежними.

Статус «Передано принтеру» означает принятие очередью Windows, не подтверждает выход бумаги. При ошибке проверьте бумагу и очередь перед повтором: часть этикеток могла уже выйти. Агент не повторяет отправку автоматически. Проверка --check проверяет сервер и токен, не принтер.

Mac с сервером должен оставаться включённым, с интернетом, без сна; временный туннель тоже должен работать. При смене ссылки обновите MARKIFY_URL и перезапустите агент. Физическая совместимость Windows-драйвера с XP-365B ещё требует проверки на вашем ПК.
