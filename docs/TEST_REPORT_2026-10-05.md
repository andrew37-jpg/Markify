Перед изменениями сохранён архив исходного кода `/private/tmp/markify-before-changes-20261005.tar.gz`.

## Изменения

- Создание задания, массовая печать и точная копия поддерживают `Idempotency-Key`. Повтор того же запроса возвращает первоначальный результат, в том числе при параллельных запросах. Ключ ограничен пользователем и точкой; другой запрос с тем же ключом получает HTTP 409. Новая таблица `print_requests` создаётся при запуске приложения.
- Интерфейс формирует ключ и сохраняет его при сетевой ошибке или HTTP 5xx. Повторная ручная отправка использует этот ключ. Автоматической повторной отправки на принтер нет. Кнопки защищены от повторного нажатия во время отправки.
- Массовое создание заданий происходит в одной транзакции. Ошибка создания не оставляет частично созданную партию. Неподтверждённые сроки по-прежнему пропускаются с пояснением.
- Точная копия разрешена только для задания со статусом «Передано принтеру». Для неоднозначного результата сначала требуется ручная проверка; просроченную этикетку копировать нельзя.
- История показывает по 50 заданий на странице, общее количество и навигацию. Проверены 305 записей и семь страниц. Данные выбираются только для текущей точки.
- Тесты используют собственную временную базу и тестовые настройки; настройки публичного HTTPS-сервиса больше не мешают локальному тестированию и не определяют тестовую базу.

## Проверки

Автоматический набор: `python -m pytest -q` — **89 тестов прошли**, 5 предупреждений об устаревших API тестовых зависимостей, 25,43 секунды. Новые проверки покрывают повторные и параллельные запросы, конфликт тела запроса, валидацию ключей, откат массовой партии, точную копию, страницы истории и изоляцию точек. Синтаксис обоих изменённых JS-файлов проверен через `node --check`.

В браузере на отдельной тестовой базе проверены вход, поиск, создание TCP-принтера, создание продукта, отображение цеха, ручной срок, печать двух этикеток и история. Реальный Print Agent передал исходное задание и его точную копию локальному TCP-эмулятору. Оба потока совпали побайтно (37 242 байта каждый); даты и данные двух этикеток сохранились. В проверенной вкладке ошибок JavaScript нет.

Снимок проверенного интерфейса: [history-2026-10-05.jpg](screenshots/history-2026-10-05.jpg).

Миграция выполнена на отдельных копиях обеих существующих SQLite-баз. Количество исходных записей не изменилось; `PRAGMA integrity_check` вернул `ok` для каждой базы. Исходные базы не перезаписывались.

## Подключение и границы проверки

Для стороннего API-клиента ключ запроса должен содержать 16–128 символов из `A-Z`, `a-z`, `0-9`, `_`, `-`. Используйте новый ключ для нового намерения печатать и тот же ключ с тем же адресом и телом при повторе после потери ответа. Старые клиенты без заголовка совместимы, но не получают защиту от дублирования.

Физическая печать ещё не подтверждена: на этом Mac не обнаружены установленные очереди принтеров. Требуются модель, USB/LAN, компьютер подключения, размер этикетки и пробная печать на самом оборудовании. TCP-передача и принятие системной очередью не подтверждают выход бумаги. PostgreSQL и настоящий Windows-драйвер в этой проверке не запускались.

Существующий `.env` настроен для публичного HTTPS-доступа. Для запуска рабочей копии используйте его HTTPS-схему; браузерная проверка выполнялась с отдельными локальными настройками и базой.
