# Политика сроков годности Markify

## Источник данных

Пользовательский перечень из PDF используется как исходный каталог продуктов. Сам PDF не задает точные значения срока годности для каждой позиции.

## Правило системы

### `needs_confirmation`
Срок не подтвержден. Автоматический расчет запрещен. При печати оператор должен указать `Годен до` по маркировке изготовителя, утвержденной технологической документации или другому документу, на который ссылается ресторан.

### `verified + auto_from_shelf_life`
Срок подтвержден. Система рассчитывает `Годен до = время изготовления + подтвержденная длительность`.

### `manual_expiry`
Дата/время окончания вводится пользователем. Значение сохраняется в PrintJob и попадает в историю.

## Что нужно подтвердить для перевода позиции в автоматический режим

- конкретный производитель;
- точное наименование и фасовка;
- температура и условия хранения;
- состояние продукта: закрытая упаковка / после вскрытия / размороженный / приготовленный;
- утвержденная технологическая или технико-технологическая документация для продукции ресторана;
- при необходимости — документы/обоснование срока годности.

## Нормативная логика

Актуальные материалы Роспотребнадзора указывают, что срок годности и условия хранения пищевой продукции устанавливает изготовитель; для продукции общественного питания применяются технические документы, а установленные сроки должны соблюдаться при хранении и реализации. Поэтому система не заполняет generic-значения «на глаз».
