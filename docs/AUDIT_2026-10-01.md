# Markify — аудит записи экрана 01.10.2026

## Зафиксированные проблемы

1. В каталоге в нескольких местах отображались битые изображения. Решение: встроенный SVG endpoint `/product-icons/{id}.svg` + placeholder fallback.
2. При ручном вводе срока печать завершалась на клиенте ошибкой `Unexpected token ... Internal Server Error`, потому что JS безусловно вызывал `response.json()`. Решение: безопасный разбор ответа + JSON-обработчик 500.
3. Перепечатка не открывалась: UI отправлял GET на endpoint, который был объявлен POST. Решение: endpoint сделан GET preview, фактическое создание новой маркировки остается POST `/api/print-jobs`.
4. `datetime-local` ранее преобразовывался `new Date(...).toISOString()`, что зависело от часового пояса компьютера. Решение: отправлять локальную строку без offset и интерпретировать ее сервером в timezone точки.
5. Браузерная печать остается fallback-режимом; для production нужен Print Agent + реальный тест принтера.
