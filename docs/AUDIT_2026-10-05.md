# Аудит тестовой готовности — 5 октября 2026

Объект: текущая папка Markify 2. Проверены запуск FastAPI, имеющиеся регрессионные тесты и путь печати Windows/USB. Это аудит готовности к пробному запуску, не полный аудит безопасности или готовности коммерческого SaaS.

## Вывод

В исходной версии 74 теста проходят. Главный блокер указанного сценария — отсутствие Windows USB-адаптера: CUPS вызывает команду lp, которой в стандартной Windows нет. Добавлен Windows / USB через pywin32 и Pillow ImageWin; используем установленный драйвер, точное имя очереди, отдельную страницу на каждую этикетку. Перед отправкой проверяются все макеты и совпадение размера бумаги драйвера (допуск 1 мм). При ошибке документ прерывается, контекст освобождается. Размер/ориентация бумаги задаются в драйвере Windows. USB002 — порт, не имя очереди.

Основной прогон: 77 тестов прошли. После добавления загрузки агента четыре целевых теста Windows/архива прошли; всего в наборе 78 тестов. Три новых теста проверяют две страницы, отказ при неверном размере бумаги и прерывание при ошибке драйвера. Эти тесты имитируют Windows API и не подтверждают работоспособность конкретного драйвера XP-365B.

Добавлена авторизованная загрузка архива агента: только файлы агента, адаптер/макет, шрифты, зависимости, пример настройки и инструкция. База и действующие секреты не включены. Для публичного теста создана отдельная pilot.db, новый случайный пароль/секрет сессии, HTTPS-only cookie и production-проверки настроек. Исходная база сохранена.

## Что остаётся до завершения продукта

1. На реальном Windows ПК: тестовая страница драйвера, настройка фактической этикетки, установка агента, одна и две этикетки, кириллица/даты/поля/подача, точная копия и обрыв связи. При неопределённом результате перед повтором проверить бумагу и очередь.
2. Windows вызовы драйвера могут блокироваться. Агент пока не изолирует печать в процесс с тайм-аутом; физический прогон и проверка зависаний нужны.
3. Публичный тест использует временный туннель к Mac, а не автономный хостинг. Mac/сервер/туннель должны быть включены. Постоянное размещение, резервное копирование и мониторинг ещё нужны.
4. Идемпотентность создания заданий отсутствует: повтор запроса может создать дополнительное задание. История ограничена 300 записями, нужна пагинация.
5. Подтверждённые сроки хранения должен внести ресторан. Каталог из 147 продуктов не является утверждённым справочником сроков.
6. Управление сотрудниками/восстановление доступа, PostgreSQL, нагрузки и независимая проверка безопасности остаются за рамками этого прогона.

Технические источники: https://pillow.readthedocs.io/en/latest/reference/ImageWin.html и https://github.com/mhammond/pywin32/blob/main/win32/Demos/print_desktop.py .

## Внешняя проверка

https://0cea3934a59c47.lhr.life — тестовый адрес localhost.run. Проверены HTTP 200 health, страница входа, панель, продукты, принтеры, история, цеха и загрузка архива; вход возвращает 303. При повторном использовании HTTP-соединения был единичный обрыв туннеля, повтор с новым соединением прошёл. Временный туннель не имеет гарантии стабильности. Cloudflare в данной среде не подключился из-за DNS; его выданные адреса не используются.

Бесплатный localhost.run сменил адрес во время проверки; первый адрес вернул 502 no tunnel. Адрес может меняться автоматически, стабильная ссылка требует другого туннеля или постоянного хостинга.

## Исправления интерфейса после теста на ПК

CSS display переопределял hidden у карточек и блоков. Добавлено общее [hidden]{display:none!important}. Страничные скрипты включены в HTML, чтобы исключить отдельный запрос через нестабильный туннель; это уменьшает риск потери скрипта, но не доказывает причину исходного сбоя на Windows. Добавлена подсказка о ненастроенном принтере с переходом к Windows / USB. Одиночная печать не активируется без принтера даже после ввода срока. Браузером проверены фильтр пустого цеха (0 видимых карточек), открытие карточки, отмена и «Добавить принтер»; ошибок JavaScript нет. 10 связанных тестов прошли. В тестовой базе нет принтера, все 147 продуктов без цеха и подтверждённого автоматического срока. Для массовой печати нужна настройка.
