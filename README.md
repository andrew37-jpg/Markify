Сервис маркировок для ресторанов на Python/FastAPI: каталог, цеха, сроки, очередь печати и локальный Print Agent. Основная кнопка «Печать» отправляет задание агенту; диалог браузера и сохранение PDF не используются.

## Установка на Mac / PyCharm

Python 3.12. Откройте папку проекта и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp -n .env.example .env
python scripts/init_db.py
python run.py
```

Адрес: http://127.0.0.1:8000. Локальная демонстрационная учётная запись: `admin@markify.local`, пароль `ChangeMe-Please-2026!`. После входа смените пароль. Это не настройки для публичного доступа.

Альтернатива: запустите `install_mac.command`. Если Finder не разрешает запуск, из Terminal: `bash install_mac.command`.

Архив сохраняет предоставленную базу: 147 продуктов, 3 задания, 6 маркировок и 3 записи принтеров. Не считайте эти записи доказательством физической печати. База автоматически обновляется при запуске. Старые токены принтеров не известны из хэшей: используйте сохранённый токен либо создайте новое подключение.

## Обновление установленного проекта

1. Остановите Print Agent. Сделайте резервную копию **своей актуальной базы**, а не базы из нового архива. Для SQLite можно выполнить новым скриптом из проекта с настроенным `DATABASE_URL`:

   ```bash
   python scripts/backup_db.py --output backups/markify-before-0102.db
   ```

2. Остановите сервер. Замените код, сохранив свой `.env`, `agent/.env` и папку `data`. **Не перезаписывайте рабочую базу базой из архива.**
3. Выполните `pip install -r requirements.txt`, затем `python scripts/init_db.py` и запустите сервер.
4. Обновите агент из этой же сборки и его зависимости. Старый агент несовместим с новым подтверждением захвата задания (`X-Print-Claim`). Войдите заново: старые cookie больше не действуют.
5. Проверьте размер этикетки, DPI и тестовую печать. Старые задания без выбранного принтера нужно отменить в истории и создать заново. Для старого Godex теперь нужна системная очередь; прямой EZPL не заявляется.

Если миграция не прошла, не продолжайте работу с частично обновлённой копией: остановите сервер, восстановите согласованную резервную копию вместе с предыдущим кодом. PostgreSQL-миграция добавляет столбцы, но в этой среде PostgreSQL не проверялся.

## Подключение принтера

1. Откройте «Принтеры», добавьте подключение, укажите фактические размер этикетки и DPI.
2. Для Xprinter/TSC выберите TSPL и сетевой IP; для Zebra — ZPL. Модель должна поддерживать выбранный язык. Настройка TSPL в этой версии рассчитана на этикетки с зазором 2 мм.
3. USB и системные драйверы macOS/Linux: выберите CUPS/Атол/Godex и имя установленной очереди из `lpstat -p -d`. Эти варианты отправляют макет через драйвер, не сырые текстовые строки. Совместимость зависит от установленного драйвера и модели.
4. Сохраните показанный токен в `agent/.env` по образцу `agent/.env.example`.
5. На компьютере рядом с принтером:

   ```bash
   source .venv/bin/activate
   pip install -r requirements-agent.txt
   python agent/agent.py --check
   python agent/agent.py
   ```

`--check` проверяет доступ к серверу и токен, **не связь с физическим принтером**. Для удалённого сервера в `MARKIFY_URL` нужен его настоящий HTTPS-адрес. Сервер и агент остаются запущенными.

## Поведение печати

- Создано → Печатается → Передано принтеру. Последний статус означает передачу данных TCP или принятие системной очередью, а не подтверждение выхода бумаги.
- После потери связи или неоднозначной ошибки — «Требует проверки». Сначала убедитесь, что этикетка не вышла, затем повторяйте; автоматической повторной отправки нет.
- «Повторить» сохраняет изготовление, срок, название, оператора, цех и условия хранения исходной этикетки. Просроченная копия запрещена.
- «Новая партия» создаёт новую маркировку и не должна использоваться для продления срока прежней продукции.
- «Завершить» убирает использованную/списанную маркировку из контроля, сохраняя историю. «Отменить» доступно для задания до захвата агентом.
- Встроенный каталог содержит 147 продуктов без подтверждённых автоматических сроков. Заполняйте сроки по документации ресторана/изготовителя. Массовая печать пропускает неподтверждённые позиции и сообщает об этом.
